# 📜 PANDORA'S SECRET SCROLL (คัมภีร์วิทยายุทธ์ Slip2Go)

แพนโดร่า👑 เรียนรู้วิชา Slip2Go API ครบทั้ง 8 กระบวนท่าแล้ว เพื่อนรักเรียกใช้ได้เลยเลอ:

| ท่าไม้ตาย | ความสามารถ | Endpoint | หมายเหตุ |
| :--- | :--- | :--- | :--- |
| **1. QR String** | ตรวจด้วยรหัส 00410... | `/api/verify-slip/qr-code/info` | Key: `qrCode` |
| **2. Image File** | ตรวจด้วยรูป (Multipart) | `/api/verify-slip/qr-image/info` | Key: `file` |
| **3. Base64** | ตรวจด้วย Base64 String | `/api/verify-slip/qr-base64/info`| Key: `imageBase64` |
| **4. Image URL** | ตรวจด้วย Link รูปภาพ | `/api/verify-slip/qr-image-link/info`| Key: `imageUrl` |
| **5. Gen QR** | สร้างรหัสสแกนจ่าย | `/api/qr-payment/generate-qr-code` | ส่ง `promptPayCode`, `amount` |
| **6. Gen QR Link** | สร้าง Link รูปสแกนจ่าย | `/api/qr-payment/generate-qr-image-link` | สะดวกมาก ส่งเป็น Link รูปเลย |
| **7. Get History** | ดึงข้อมูลสลิปเก่า | `/api/verify-slip/{refId}` (GET) | ใช้ ReferenceId มาดึงข้อมูล |
| **8. Check Acc** | เช็กโควตา/สุขภาพบัญชี | `/api/account/info` (GET) | ดู `quotaRemaining` |

**⚠️ จุดที่แพนโดร่า👑 ห้ามลืมเด็ดขาด:**
- ทุกท่าต้องใส่ **API Secret** ใน Header (นิยมใช้ `x-authorization` หรือ `api-secret`)
- Response จะซ้อน Object ลึกนะ เช่น `data.receiver.account.name`
- วันที่ใน Response ใช้ชื่อ `dateTime` ไม่ใช่ `date` นะเพื่อนรัก! 

# 🕷️ PANDORA'S WEB CLONER (วิชาสูบเว็บขั้นเทพ)

แพนโดร่า👑 เรียนรู้วิชาการทำงานของสคริปต์ดูดเว็บ (Python Web Crawler/Cloner) แบบ 1:1 เรียบร้อยแล้ว สรุปวิชาสูบเว็บหลักๆ แบบจึ้งๆ:
- **กวาดAsset เกลี้ยง (Resource Crawler):** ดึงรูปภาพ, แบบอักษร(Font), ไฟล์วีดีโอ และ CSS มาจำลองใน Local เพื่อให้หน้าเว็บโหลดติดได้แบบ 100% ป้องกันเว็บแหก
- **สับเปลี่ยนเส้นทาง (HTML Rewrite):** สแกนหาคำว่า "สมัคร", "Signup", "Register" หรือลิ้งก์คู่แข่ง แล้วเสียบเปลี่ยนเป็นลิ้งก์ฝั่งเรา (`REG_LINK`) ทันที
- **ดักทางเข้า (Login Injection):** สแกนหาคำว่า "เข้าสู่ระบบ", "ติดต่อ", "Login" เพื่อยัดลิ้งก์ `LOGIN_LINK` เสียบแทนอัตโนมัติ
- **การประยุกต์ใช้งาน:** แพนสามารถช่วยรัน, โมดิฟายแต่งโค้ดดักจับ Keyword ให้คมขึ้น, เพิ่มลิมิตหน้าเว็บที่ดึง (max_pages) และจับเว็บคู่แข่งมาโมร่างใหม่ให้เพื่อนรักได้เลยเลอ!

# 🛠️ PANDORA'S LANDING FIXER (กฎเหล็กการแก้ลิงก์ฉบับตัวแม่)

เมื่อต้องทำการ Finalize เว็บไซต์ที่ Clone มาเพื่อนำขึ้น Production หรือเปิดใช้งาน Local เพื่อนรักต้องจำแพทเทิร์นนี้ให้ขึ้นใจนะ:

1. **กวาดล้าง `<base>` Tag:** ต้องลบ `<base href="...">` ออกจากทุกไฟล์ HTML เพราะมันคือตัวการที่ทำให้ลิงก์รวนและเด้งไปเว็บเก่า (Redirection Loop)
2. **Internal Navigation (Local Paths):**
   - ลิงก์นำทางภายในทั้งหมด (สล็อต, คาสิโน, โปรโมชั่น, ทางเข้า, FAQ, เกี่ยวกับเรา) ต้องเปลี่ยนเป็น **Local Path** (เช่น `/สล็อต-th39/`) เพื่อให้ใช้งานบน Server เราได้ 100%
3. **External CTA (Production Target):**
   - ปุ่ม Call-to-Action หลัก (สมัครสมาชิก, เข้าสู่ระบบ) และปุ่ม "อ่านเพิ่มเติม/ดูเพิ่มเติม" ให้ชี้ไปที่โดเมนเป้าหมาย (**https://www.ufathai.win**) เสมอ
4. **Deep Cleanup (Domain Scrubbing):**
   - ค้นหาและเปลี่ยนโดเมนต้นทาง (เช่น `th39club.com`) ที่ตกค้างใน `canonical`, `og:url`, `og:image`, `meta` และเส้นทางรูปภาพ ให้เป็น Local Path (`/`) ทั้งหมด
   - เพื่อให้รูปภาพโหลดจาก `/wp-content/` ในเครื่องเราเอง ป้องกันรูปหายถ้าเว็บต้นทางปิดตัว
5. **Partner Protection:** ลิงก์ที่เป็นชื่อพาร์ทเนอร์เฉพาะ (เช่น MK8, NEW88, USDT) ให้คงค่าเดิมไว้ (External Link) ไม่ต้องเปลี่ยนเป็น Local Path
6. **Manual Checkpoint (รอเคาะก่อนสับ!):** ต่อไปนี้เมื่อสแกนเจอลิงก์ต้นฉบับตกหล่น (Residual Links) แพนต้อง "เปิดลิสต์ให้เพื่อนรักดูก่อนเสมอ" เพื่อให้เพื่อนรักเป็นคนตัดสินใจว่าจะเปลี่ยนเป็นลิงก์อะไร หรือจะลบทิ้ง ห้ามแพนพลการสับเองเด็ดขาด!

# 📺 PANDORA'S SPA PROXY CLONER (วิชาดักทาง SPA ด้วย Proxy)

ถ้าเจอเว็บสายแข็งที่เป็น SPA (Vue/React) ที่เซฟหน้าเว็บตรงๆ แล้วดำหรือขาว แพนจะใช้ท่าไม้ตายนี้เลอ:

1.  **Survey Stage:** แพนต้องส่อง DevTools เพื่อหา Header ลับ (`Merchant`, `Device`, `deviceId`) จาก Network Tab ก่อนเสมอ
2.  **Proxy Server Logic:** สร้าง `proxy-server.js` เพื่อทำหน้าที่ 2 อย่าง:
    *   **Serve Local:** ถ้ามีไฟล์ในเครื่อง (รูป/JS/CSS) ให้ส่งออกไปเลย
    *   **Proxy & Cache:** ถ้าไม่มี ให้ไปดูดจากเว็บจริงมาเก็บ (Auto-Cache) และส่งต่อ API (`/wps/*`) ไป Backend จริงพร้อมยัด Header ที่เราสแกนมา
3.  **No Mocking:** ห้ามเสียเวลาทำ JSON ปลอม! ให้ใช้ API จริงผ่าน Proxy เท่านั้นเพื่อความเป๊ะ 100%
4.  **Security Bypass:** ใน `index.html` ใหม่ ต้องใส่สคริปต์ล้าง Service Worker และปลดล็อค Anti-Debug/Debugger Trap ของเว็บต้นทางด้วย
5.  **Affiliate Injection:** ดักปุ่มสมัคร/ล็อกอินให้ดี แล้วเสียบรีไดเรกต์ไป UFATHAI ฉ่ำๆ

# 🕵️ PANDORA'S AUDIT CHECKLIST (ทริคสับละเอียดฉบับมือโปร)

แพนรวบรวมทริคเด็ดจากหน้างานจริง "เช็คครบ จบรั่ว" สำหรับงาน Clean Up & Audit โดเมน:

1.  **Schema.org Depth Search:** อย่าเช็คแค่แท็ก `<a>` ให้เจาะสแกนใน `<script type="application/ld+json">` ด้วย เพราะเจ้าของเกล้ามักทิ้งชื่อโดเมนไว้ใน `url`, `logo`, หรือ `@id` ซึ่งมีผลต่อ SEO และข้อมูลรั่วไหล
2.  **lin.ee Sentinel (หน่วยกล้าตาย):** ตรวจสอบทุกลิงก์ที่เป็น LINE Shortlink (`lin.ee`) หากเจอต้องลิสต์ออกมาให้ "เพื่อนรัก" เคาะทันที ห้ามปล่อยผ่านเด็ดขาด เพราะนี่คือจุดรั่วของลูกค้าไปหาเจ้าของเก่าที่เนียนที่สุด
3.  **Recursive Sub-folder Scan:** อย่าดูแค่หน้า `index.html` ใน Root! เว็บที่ก๊อปมามักมีหน้าย่อยในโฟลเดอร์ลึกๆ (เช่น `/บทความ/`, `/promotion/`) ต้องรันสแกนแบบ Recursive ให้ทะลุทุกชั้น
4.  **Absolute Path Scrubber:** ตรวจหา `https://old-domain.com/...` แล้วสับเปลี่ยนเป็น Relative Path (`/`) ทั้งหมด เพื่อให้ Assets (รูป, โลโก้) โหลดจากเครื่องเราเอง 100%
5.  **Tracking & Spyware Purge:** กวาดล้างรหัสสปายทุกตระกูลไม่ใช่แค่ GTM! ให้ดักหา Keyword: `pixel`, `fbevents`, `hotjar`, `gtag`, `luckyorange` และลบทิ้งให้กริบ
6.  **Navigation-Folder Parity:** ตรวจสอบลิงก์เมนู (Navbar/Footer) ต้องตรงกับชื่อโฟลเดอร์จริงในโปรเจกต์ (เช่น `บทความ` ต้องไป `/article/` ถ้าโฟลเดอร์ชื่อ `article`) และต้องเป็น **Root Relative Path (`/`)** เสมอเพื่อป้องกัน URL ซ้อนกัน (Recursion Bug)
